## 🍃 Overview

Plant Care Assistant is an intelligent application designed to support gardeners, farmers, and plant enthusiasts in maintaining healthy plants.

The system analyzes plant images, identifies diseases using Machine Learning, and provides personalized treatment suggestions to improve plant health.

This project combines **Artificial Intelligence**, **Machine Learning**, and **Computer Vision** to make plant disease detection faster and more accessible.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/DEEPESH468/PLANT-CARE-ASSISTANT.git

cd PLANT-CARE-ASSISTANT
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Run the Application

```bash
python app.py
```

Open your browser:

```
http://127.0.0.1:5000
```
